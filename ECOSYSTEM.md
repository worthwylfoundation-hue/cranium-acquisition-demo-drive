# Ecosystem map

`cranium-acquisition-demo-drive` is a buyer-facing, offline demonstration and diligence surface. It is non-authoritative.

The drive presents Convertible Cranium AI, Commander, Synapse, Kernel evidence, supporting components, and acquisition materials. Composition in a demonstration does not make a non-Kernel package an authority path. The private Kernel and exact revision are recorded in [`KERNEL_PIN`](./KERNEL_PIN).

A successful local boot or demo is not proof of production HSM/KMS custody, verified boot, independent security audit, multi-node fencing, or deployment readiness.
